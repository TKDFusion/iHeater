# Changelog

Этот файл ведётся на русском языке и фиксирует заметные изменения в проекте iHeater — плате нагревателя и её документации.

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [3.0.0]

### Добавлено

- **Третий способ управления: iHeater Link.** Модуль связи берёт уставку камеры у принтера и передаёт её нагревателю по одному сигнальному проводу. Появляются портал, мобильное приложение и интеграции с Home Assistant, Moonraker и Bambu Lab. Прошивку принтера трогать не нужно.
- **Плата ревизии 1.1: третий термистор.** Ставится на стол принтера и служит триггером автозапуска: нагрев включается с началом печати и выключается по остыванию стола. Для автономной прошивки.
- Раздел частых вопросов и калькулятор предварительного расчёта температуры в камере.

### Изменено

- **Подключение питания.** Основной вариант — кабель через гермоввод в стенке корпуса на винтовые клеммы, с коммутацией от силовой линии принтера. Как альтернатива на корпус ставится разъём C8. Ориентация платы свободная.
- Разводка платы: улучшено размещение компонентов и трассировка.
- Ревизия 1.1 совместима по выводам с предыдущей, кроме третьего термистора.

## [2.x и ранее]

Серия пробных сборок платы. Направление завершено, наработки перенесены в 3.0.0.
